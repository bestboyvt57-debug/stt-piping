LOCATION APP - PTSC V4

CACH SU DUNG
1. Giai nen TOAN BO file trong ZIP vao cung mot thu muc, vi du Desktop\Location_App_V4.
2. Nhan dup Start_Location_App_V4.bat.
3. Cong cu tu tim thu muc local_site va tu mo trinh duyet.
4. Giu cua so den khi su dung xong. Nhan Q trong cua so de tat web server.

V4 KHONG CAN PYTHON. Cong cu dung bo may TCP/HTTP tich hop trong Windows PowerShell.

Neu khong tu tim thay local_site, hop thoai se hien ra. Chi chon thu muc local_site
co ca index.html va thu muc 3d ben trong. Khong chon index.html rieng le.

Neu Windows hien canh bao, chi chay file BAT trong thu muc da giai nen. Khong can chay voi quyen Administrator.
